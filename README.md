# 

Data Cleaning and Basic Analysis

Project Overview

This project focuses on cleaning, exploring and performing basic statistical analysis of a biological gene-expression dataset.

Dataset Information

- Source: NCBI Gene Expression Omnibus (GEO)
- Accession: GSE42568
- Research area: Breast cancer gene expression
- Samples: 121
- Cancer samples: 104
- Normal samples: 17
- Platform: GPL570

Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

Work Performed

1. Dataset loading and exploration.
2. Missing-value assessment.
3. Duplicate probe removal.
4. Infinite-value handling.
5. Basic statistical analysis.
6. Sample classification.
7. Gene-expression distribution visualization.
8. Exporting cleaned data and statistical results.

Results

- Original dataset dimensions: 54,675 × 122.
- Missing values in the cleaned dataset: 0.
- Cancer samples: 104.
- Normal samples: 17.

Repository Files

- "SWYNEX_Task2_Data_Cleaning_Analysis.ipynb" – Analysis notebook.
- "cleaned_GSE42568.csv.gz" – Cleaned dataset.
- "sample_metadata.csv" – Sample information.
- "sample_statistics.csv" – Sample-level statistics.
- "group_expression_summary.csv" – Group-level summary.
- "expression_distribution.png" – Visualization.

Learning Outcomes

This task provided practical experience in biological data handling, data cleaning, descriptive statistics and scientific data visualization.
